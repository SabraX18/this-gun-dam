# This Gun-Dam?

Phase 1 mobile-first Phaser/TypeScript prototype for Sabra 18א.

## Run

```bash
npm install
npm run dev
```

Open the local Vite address in a browser. For phone testing, use the Vite network URL on the same Wi-Fi, and rotate to landscape.

## Controls

- Mobile: drag on the left half to move; tap SPECIAL when charged.
- Desktop testing: WASD or arrow keys; Space for special.
- Energy Saber attacks the nearest enemy automatically. Collect glowing energy cores to level up, and select one of three upgrades.
- Pause via the upper-right button. Local save snapshots are made every 30 seconds.
